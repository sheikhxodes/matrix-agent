# Tools

All tools are Python functions wrapped with `FunctionTool` from Google ADK.

## Code Tools

| Tool | Description |
|------|-------------|
| `create_project` | Scaffold new project |
| `generate_component` | Create UI component |
| `setup_auth` | Configure authentication |
| `setup_database` | Initialize database |
| `integrate_stripe` | Add Stripe payments |
| `run_e2e_tests` | Execute E2E tests |
| `deploy_app` | Deploy to cloud |

## PPT Tools

| Tool | Description |
|------|-------------|
| `create_presentation` | Initialize presentation |
| `add_slide` | Add new slide |
| `generate_chart` | Create data visualization |
| `apply_design` | Apply theme/design |
| `export_pptx` | Export to PPTX |

## Browser Tools

26 tools for CDP automation including:

- **Input:** click, drag, fill, hover, press_key
- **Navigation:** navigate_page, new_page, close_page
- **Capture:** take_screenshot, take_snapshot
- **Debug:** evaluate_script, get_console_message
- **Performance:** start_trace, stop_trace, analyze_insight
